__________DATA FLOW of index.php___________


STEP 1 ______

When the JS frontend submits the form via fetch(), PHP sees a POST request. The first thing it does is declare: "my response will be JSON" — so the browser knows how to parse what comes back.

STEP 2 _____
validate_image() — is the file safe?

$_FILES is PHP's way of accessing uploaded files. The function does two checks:
Size: if the file is over 5 MB, throw an exception — stops junk uploads early.
MIME type: uses finfo, a PHP built-in that reads the actual file bytes (not just the filename extension, which users can fake). Only JPEG, PNG, and WebP are allowed. Returns the MIME type string (e.g. "image/jpeg") if valid.


STEP 3_______ — file_to_base64() — convert image to a string

PHP saves uploaded files to a temporary path on the server. This function reads those raw bytes with file_get_contents(), then encodes them as base64 and prepends the data URI prefix:

Why? Replicate's API expects everything in one JSON body. You can't send a binary file inside JSON directly — base64 turns the binary into a plain text string that fits inside a JSON field. No separate file upload endpoint needed.
